## The DC9 Plan 是个什么套餐

The DC9 Plan 是搬瓦工（BandwagonHost）在 2024 年 4 月推出的限量版 KVM VPS，也是他家近几年少有的低价走量款。它唯一的卖点其实就一条：用入门级的价格，拿到洛杉矶 DC9（USCA_9）机房的 CN2 GIA 线路。

| 硬盘 | 15 GB SSD（RAID-10） |
| 月流量 | 750 GB |
| 带宽 | 1.5 Gbps |
| 机房 | 洛杉矶 DC9 CN2 GIA（固定，不支持迁移） |
| 虚拟化 | KVM / KiwiVM 面板 |
| 价格 | $38.00/年（原价） |

配套功能包括免费自动备份、免费快照、一键重装系统（AlmaLinux、Debian、Ubuntu 等模板）、IPv4 + IPv6 /64、rDNS 自助设置，这些是搬瓦工全系套餐的标配。

## 线路才是它真正的价值：三网回程 CN2 GIA

先说清楚 CN2 GIA 为什么值钱。搬瓦工官网对几种中国线路的差别写得很直白：普通的 163 骨干网（AS4134）便宜但晚高峰拥堵严重，丢包率可以到 30% 以上；CN2 GT（AS4809 的低端档）原本是为了解决拥塞，现在表现和 163 差不多；而 CN2 GIA（AS4809 高端档）是电信最贵、也最稳定的一条路，网页、视频会议、联机游戏这类对延迟和丢包敏感的用途，基本只有它扛得住。代价是贵——官方页面提到，CN2 GIA 的 IP transit 成本在部分市场可以高达每兆比特 $120，容量还非常紧张，所以提供 CN2 GIA 的套餐普遍不便宜，也不抗 DDoS。

The DC9 Plan 的路由结构是这样的：去程电信走 CN2 GIA，联通和移动直连；回程三网（电信 CN2 GIA、移动 CMIN2、联通 AS10099 精品网）都走优化线路。这一点和官网对 USCA_9 机房的描述一致——所有回中国方向的流量分发到这三个运营商。

有第三方测评站（HostHum）在套餐首发时跑过测试，结论大致是：网络符合预期，国内方向单线程轻松跑过 100 Mb/s，回程三网确实全程 CN2 GIA；但 CPU 性能偏弱，磁盘性能中规中矩。这个短板跟下一节要说的 CPU 限制直接相关。

## 便宜不是没代价：CPU 限制和使用政策

The DC9 Plan 是"限量版"系列的一员，而搬瓦工所有限量版套餐都执行 Fair Share CPU 政策。官方服务条款（2025 年 11 月 26 日修订版）里写得明确：The DC9 Plan 的小时平均 CPU 用量上限是单核的 30%。也就是说，短时间你可以跑满 1 核，但持续负载一旦超过平均 30%，CPU 会被自动限速，降到限额以内才恢复。跑静态站、反代、Telegram bot、轻量 Docker 这种占不了多少 CPU 的任务没影响；想拿它编译代码、跑爬虫或者当小型计算节点，会被限制卡住。

其他政策也值得看一眼：

- 磁盘 I/O 持续超过 100 MiB/s 超过 4 小时，官方会邮件提醒，无视提醒可能被临时暂停。
- BitTorrent、加密货币挖矿、对外做种的完整禁令写进了 ToS，挖矿是明确违规项。
- 该套餐在 KiwiVM 后台不支持机房迁移，买定离手，IP 什么样就是什么样。
